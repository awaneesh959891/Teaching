# College Portal Web Application

Welcome to the College Portal Web Application! This project is a web-based platform designed to streamline communication and management for students, staff, and administrators.

## 🌟 Features

- **Student & Staff Login:** Secure authentication for students and staff members.
- **Registration:** Easy online registration for new users.
- **Password Recovery:** Forgot password functionality for both students and staff.
- **Feedback & Contact:** Users can submit feedback and contact the administration directly.
- **Admin Panel:** Manage categories, view reports, and oversee portal activities.
- **Download Center:** Access important documents and resources.
- **Responsive Design:** User-friendly interface with custom styles ([style.css](style.css)) and images.

## 🚀 Getting Started

1. **Clone the repository:**
   ```sh
   git clone https://github.com/yourusername/college-portal.git
   ```

2. **Open in Visual Studio:**
   - Open the solution in Visual Studio.
   - Restore NuGet packages if required.

3. **Configure Database:**
   - Update your database connection string in [web.config](web.config).

4. **Run the Application:**
   - Press `F5` or click "Start" in Visual Studio to launch the portal.
